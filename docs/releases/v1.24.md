# OpenLadder Studio v1.24

## Verificação da gravação PG33 sem nova escrita

A gravação de um projeto real pela v1.23 foi confirmada fisicamente no WEG TP02-60MR: o controlador respondeu ao quadro PG33 com ACK `00 00 FF` e o PC12 mostrou o novo programa no início da memória (`STR X0001`, `OUT Y0001`, `F-00 END`).

A falha observada estava apenas na reconexão automática usada para o readback após a gravação. A v1.24 separa essas duas operações.

### Novo comando: VERIFICAR GRAVAÇÃO

A tela PG33 passa a oferecer **VERIFICAR GRAVAÇÃO**. Esse comando:

- recompila o projeto Ladder atual para obter a referência esperada;
- mantém o TP02 em modo somente leitura durante a verificação;
- tenta reacquirir o enlace PG em até oito rodadas;
- executa apenas a sequência de qualificação/leitura `HELLO/F0/38/34`;
- compara o readback com o projeto compilado;
- informa confirmação quando o conteúdo é idêntico;
- não transmite PG33;
- não faz restauração;
- não envia RUN remoto.

Se a comunicação continuar instável, o usuário pode executar **VERIFICAR GRAVAÇÃO** novamente sem risco de repetir a escrita.

## Mensagem após ACK corrigida

Quando o TP02 responde `00 00 FF` e somente o readback posterior falha, a mensagem passa a distinguir claramente os estados:

- a gravação foi aceita pelo TP02;
- o PG33 não será reenviado automaticamente;
- a confirmação está pendente por falha de reconexão;
- o usuário deve usar **VERIFICAR GRAVAÇÃO** para conferir o conteúdo sem nova escrita.

## Atualizador corrigido

O downloader assíncrono do atualizador mantinha o `WebClient` dentro de um bloco `using`. Isso permitia que o objeto fosse descartado logo depois de iniciar `DownloadFileAsync`, interrompendo a transferência.

Na v1.24 o cliente de download permanece vivo até o evento de conclusão, é liberado somente depois do término e volta a habilitar a atualização em caso de erro. A correção vale para a v1.24 em diante; uma instalação v1.23 que ainda apresente a falha pode precisar receber a v1.24 manualmente uma última vez.

## Memória após F-00 END

A leitura física confirmou que palavras antigas podem permanecer depois do novo `F-00 END`. Elas não pertencem ao programa ativo: o snapshot e a comparação do OpenLadder encerram no primeiro `F-00 END`, seguindo o comportamento observado no PC12.

## Segurança preservada

- gravação somente com PLC em STOP;
- backup anterior ao PG33;
- cada gravação PG33 transmitida no máximo uma vez;
- readback independente da escrita;
- nenhuma retransmissão cega;
- nenhuma restauração cega;
- nenhum RUN remoto, Clear All, WBP ou escrita `0x09`.

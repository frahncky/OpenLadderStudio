# OpenLadder Studio v1.11

## Prova física controlada do comando PG33

Esta versão adiciona uma ferramenta específica para validar fisicamente o comando proprietário PG/PC12 `0x33` (Write PLC Program) no WEG TP02, sem alterar a lógica do programa já validado em bancada.

### Fluxo da prova

A opção **PLC > Validar escrita PG33 (sem alterar programa)...** executa:

1. comunicação PG/PC12 em **19200 8O1, DTR=OFF, RTS=OFF**;
2. confirmação de **STOP** pelo HELLO;
3. leitura completa por `F0 -> 38 -> 34`;
4. backup automático do programa antes da escrita;
5. gate rígido: somente a assinatura canônica de **23 passos / END=0022** já validada na v1.10 é aceita nesta primeira prova;
6. reconstrução do quadro `0x33` com os mesmos HIGH/LOW do programa atual;
7. plano `EXTERNAL=00` somente porque isso foi confirmado offline para a assinatura canônica; o BRAW do `34` não é reutilizado como EXTERNAL;
8. até 3 tentativas do PG33, seguindo o limite reconstruído do PC12 original;
9. captura do ACK físico bruto e validação de enquadramento/checksum;
10. releitura completa do programa e comparação byte a byte com o backup.

### Guardas de segurança

- qualquer PLC em RUN bloqueia a transmissão do `0x33`;
- qualquer programa diferente da assinatura física de 23 passos bloqueia a transmissão;
- nenhum `Clear All (0F 00 F0)` é enviado;
- nenhum RUN/STOP remoto é enviado;
- nenhum `0x09`, WBP ou outro comando de escrita é enviado;
- a ferramenta não altera intencionalmente a lógica: regrava somente os mesmos passos já armazenados;
- todos os quadros e relatórios são salvos em **Documentos/OpenLadder Studio/TP02 PG33 Physical Probes**.

### Objetivo

O objetivo desta etapa não é ainda habilitar download geral no OpenLadder Studio. O objetivo é obter a primeira evidência física de:

- aceitação do `0x33` pelo TP02;
- ACK físico real do PG33;
- readback idêntico após a operação.

Somente depois desta prova será preparado o teste mínimo com alteração controlada e restauração automática.

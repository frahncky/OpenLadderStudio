# OpenLadder Studio v1.29

## Interface TP02 mais clara

A barra TP02 / TP-232PG da tela principal foi redesenhada para ficar mais legível e com aparência de software industrial.

- botões maiores, com 44 px de altura;
- cantos arredondados;
- ícone/símbolo junto ao nome da ação;
- cores diferentes por função;
- estados visuais de hover e pressionamento;
- tooltips explicando a função de cada comando;
- indicador de conexão apresentado como um pill visual;
- permanece o fluxo da v1.28: CONECTAR/DESCONECTAR, LER, ESCREVER, VERIFICAR, STOP e RUN;
- sem conexão, os comandos continuam clicáveis e apenas sinalizam SEM CONEXÃO COM O TP02, sem transmitir bytes.

Cores funcionais:

- CONECTAR/DESCONECTAR: azul;
- LER: azul;
- ESCREVER: verde;
- VERIFICAR: âmbar;
- STOP: vermelho;
- RUN: verde.

## Paleta Ladder ampliada

A caixa de elementos Ladder foi redesenhada para melhorar a leitura dos símbolos e nomes das instruções.

- largura ampliada de 238 px para 326 px;
- botões de ferramenta ampliados de 208 x 34 px para 296 x 46 px;
- fonte dos elementos aumentada;
- símbolos Ladder mais destacados;
- itens organizados por grupos: Edição, Contatos, Saídas, Tempo e Contagem, Eventos e Funções;
- dicas de ferramenta mantidas para identificação rápida;
- rolagem automática preservada para telas menores.

A alteração é apenas de interface e ergonomia. A semântica das ferramentas Ladder e a lógica de comunicação TP02 não foram modificadas.

## Segurança do TP02

As regras das versões anteriores permanecem:

- WRITE exige PLC em STOP;
- VERIFY não retransmite PG33;
- PG33 não é reenviado cegamente após ACK;
- STOP/RUN continuam protegidos sem transmissão de opcode remoto desconhecido até validação física;
- nenhuma operação Clear All, WBP ou escrita 0x09 foi habilitada.

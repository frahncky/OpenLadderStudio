# OpenLadder Studio v1.00

## TP02 PG Lab - sessão limpa para leitura do programa

Esta versão publica o motor PG Lab 1.13 com foco no fluxo de leitura do programa do WEG TP02.

Principais mudanças:
- fluxo focado em `HELLO -> F0 -> 38 -> 34`;
- confirmação obrigatória de PLC em STOP antes de prosseguir;
- apenas uma tentativa de `F0` por abertura da porta serial;
- se `F0` falhar, a COM é fechada, aguarda 1500 ms e uma nova sessão começa desde o HELLO;
- `38` só é enviado após `F0` validado;
- `34` só é enviado após `HELLO`, `F0` e `38` válidos;
- resposta do `34` é validada por LEN e checksum e salva em arquivos binários para análise;
- varreduras `0A` e consulta `14` foram removidas do teste focado para reduzir ruído;
- nenhum comando de escrita, RUN/STOP remoto, download, apagamento ou firmware é enviado;
- `0F 00 F0` permanece bloqueado.

A versão também incrementa o número público para `1.00`, permitindo que o atualizador instalado detecte esta entrega como uma nova versão.

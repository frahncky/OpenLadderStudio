# OpenLadder Studio v1.06

## Correção da validação física do WEG TP02 com TP-232PG

Esta versão corrige a interpretação da validação física quando o TP02 está conectado pelo conversor **TP-232PG** e pelo protocolo proprietário **PG/PC12**.

### O que foi corrigido

- a validação não inicia mais supondo que todo TP02 esteja em Computer Link;
- a fase 1 tenta primeiro o link **PG/PC12 em 19200 8O1**, compatível com o TP-232PG;
- no teste PG somente o handshake seguro `CON-ICB<CR>` é transmitido;
- são reconhecidas as respostas HELLO físicas `C0 01 09 35` e `80 01 09 75`, ambas com soma de quadro `FF`;
- se o link PG for confirmado, o resultado passa a ser **LINK PG/PC12 APROVADO**, em vez de erro de PSR;
- se PG não for detectado, a ferramenta tenta o caminho **Computer Link 19200 7N1**, com PSR e duas leituras RBP completas para validação;
- a gravação WBP continua liberada somente em Computer Link, após leitura aprovada e estado STOP;
- em modo PG a gravação permanece explicitamente bloqueada, porque a escrita proprietária PG ainda não foi habilitada com segurança;
- o relatório da sessão agora registra qual transporte foi realmente detectado.

### Segurança

A autodetecção PG não envia RUN, STOP, WBP, comandos de limpeza ou qualquer comando PG não classificado. O teste PG usa somente `CON-ICB<CR>`.

### Para o TP-232PG

Use o mesmo cabo, conversor e porta COM que funcionam no software WEG. Feche o software WEG antes de testar para que a porta serial fique disponível e execute **PLC → Validação física final TP02 → 1. DETECTAR / VALIDAR LINK**.

# OpenLadder Studio v1.71

Esta versão faz o monitor do PLC real TP02 acender o diagrama do editor. Confira a seção "Antes de atualizar".

## Antes de atualizar

- **A leitura do PLC real ainda não foi validada no equipamento físico.** O recurso foi validado por autotestes e pela simulação, mas nunca foi executado contra um PLC TP02 de verdade. Use com cautela.

## Monitor

- Nova opção **Acender diagrama** no monitor do TP02. Ao ativá-la, o programa lê os bits X, Y, C e SC do PLC real e acende as linhas do diagrama no editor, como já acontecia na simulação.
- A leitura usa somente o comando MCR, que apenas lê o estado do PLC; nada é escrito no equipamento.
- A simulação tem prioridade: se a simulação estiver em execução, o diagrama mostra o estado simulado e não o do PLC.
- A leitura para sozinha ao fechar a aba do monitor ou quando ocorre um erro de comunicação, para não deixar o diagrama aceso com dados desatualizados.

O instalador e seu SHA-256 ficam disponíveis para download pelo atualizador do programa.

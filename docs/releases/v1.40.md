# OpenLadder Studio v1.40

## Evidências emuladas para comandos PG desconhecidos

O catálogo incorporado foi refinado após nova execução offline do `pc12.exe`:

- `03` identificado como preflight de preparação/limpeza antes do PG33;
- `04` e `11` classificados como operações pareadas de modo/serviço que exigem STOP;
- `09` associado a escrita/configuração de áreas variáveis;
- `0A` associado às leituras V, D, WC, FILE e sistema;
- `35` permanece sem função determinável pelo lado do PC12.

As classificações aparecem em `Ferramentas > Comandos PG do PC12`. Nenhuma nova
operação foi liberada para TX: o emulador não substitui a confirmação do firmware
e do comportamento físico do TP02.

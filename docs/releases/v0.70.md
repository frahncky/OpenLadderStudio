## OpenLadder Studio v0.70

### Normalização PT-BR
- a normalização deixa de traduzir literais que não são texto de interface: URLs, identificadores de API em snake_case, padrões de expressão regular e caminhos técnicos;
- a causa da corrupção passa a ser evitada em vez de reparada depois: o reparo de tokens continua no build apenas como rede de segurança;
- a varredura de tokens corrompidos passa a valer para todos os fontes, e não só para o atualizador;
- corrigida a concordância gerada pela tradução de `download`: "Falha no download." virava "Falha no transferência.".

### Atualização automática
- removida das notas da v0.69 a ponte de compatibilidade para clientes antigos: ela não podia funcionar, porque no corpo da release toda aspa volta escapada e a expressão regular do cliente exige aspa não escapada.

### Atualização manual necessária nas versões 0.66, 0.67 e 0.68
Essas três versões foram publicadas com o atualizador corrompido: ele procura o campo
`browser_transferência_url`, que a API do GitHub nunca devolve. O aplicativo chega a mostrar
que existe versão nova, mas o botão de atualizar não habilita e a mensagem fica
"Pacote de atualização incompleto.".

Nenhuma alteração no servidor alcança essas instalações. Quem estiver em 0.66, 0.67 ou 0.68
precisa instalar a v0.70 manualmente, uma vez:

https://github.com/frahncky/OpenLadderStudio/releases/latest

A partir da v0.69 o atualizador voltou a funcionar sozinho.

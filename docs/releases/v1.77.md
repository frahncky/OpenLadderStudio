# OpenLadder Studio v1.77

Esta versão corrige uma perda de dados no mapa de memória.

## Correção

- **Área sem observação não some mais.** No mapa de memória do controlador, uma área salva com a coluna Observação em branco desaparecia na próxima vez que o mapa era aberto. Agora ela é lida normalmente. Uma área que sumiu numa versão anterior volta a aparecer se o mapa não foi salvo de novo depois disso; se foi, ela precisa ser cadastrada outra vez.

## Antes de atualizar

- O formato dos arquivos não mudou nesta versão.
- O comentário de linha da v1.73 continua com compatibilidade de mão única: um projeto com comentário de linha não abre em instalações anteriores à v1.73.
- A leitura do PLC real ("Acender diagrama") continua sem validação no equipamento físico.

## Limitações conhecidas

- Na largura mínima da janela (1280 x 800), a barra de rolagem horizontal do editor aparece mesmo quando o diagrama deveria caber.
- O painel PROPRIEDADES encurta a lista INSTRUÇÕES; na janela mínima, Bobina, SET e RESET exigem rolagem.

O instalador e seu SHA-256 ficam disponíveis para download pelo atualizador do programa.

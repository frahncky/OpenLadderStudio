# OpenLadder Studio v1.08

## Estabilidade do link PG/PC12 com TP-232PG

Esta versão reforça a detecção física do WEG TP02 após a bancada confirmar que o perfil que efetivamente respondeu no conjunto testado foi **19200 8O1, DTR=off, RTS=off**, com HELLO `80 01 09 75`.

### Correções

- o perfil **DTR=off / RTS=off** passa a ser tentado primeiro;
- o perfil confirmado em bancada recebe mais tentativas e maior tempo de estabilização;
- a primeira sessão PG aguarda o TP-232PG estabilizar antes do `CON-ICB<CR>`;
- se não houver HELLO, o Studio fecha e reabre a COM automaticamente e executa uma segunda sessão;
- a recuperação mantém **DTR=off / RTS=off**, sem pulsar as linhas antes da segunda sessão;
- perfis alternativos só são tentados depois do perfil físico confirmado;
- o log informa o total de bytes recebidos quando nenhuma resposta HELLO conhecida é validada;
- o fallback para Computer Link continua ocorrendo somente depois das tentativas PG.

### Segurança

A detecção PG continua transmitindo apenas o quadro conhecido `CON-ICB<CR>`. Nenhum comando de RUN, STOP, limpeza, escrita ou transferência PG não classificado é enviado durante a estabilização.

O objetivo é reduzir as falhas intermitentes observadas entre execuções sucessivas do mesmo teste físico.

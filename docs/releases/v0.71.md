## OpenLadder Studio v0.71

### Correção crítica de inicialização
- corrigido `NullReferenceException` na abertura do OpenLadder Studio;
- `UpdateProjectName()` deixa de acessar `projectValue` quando o painel moderno não cria esse label;
- o bloco de recuperação deixa de repetir a mesma referência nula;
- adicionadas guardas para controles opcionais da interface e documentos sem referência válida;
- acesso às capacidades do driver passa a ser defensivo quando um perfil/driver estiver incompleto.

### Validação de release
- o GitHub Actions agora abre o `OpenLadderStudio.exe` após a compilação e observa o diretório do `StudioDiagnostics`;
- qualquer exceção registrada durante o startup reprova a build antes da geração/publicação do instalador;
- uma release não é mais considerada válida apenas por compilar e passar os testes do núcleo.

### Atualização
- esta versão substitui a v0.70 para corrigir o travamento observado ao iniciar a interface;
- o atualizador permanece compatível com as correções de URL e SHA-256 introduzidas nas versões anteriores.

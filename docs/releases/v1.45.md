# OpenLadder Studio v1.45

## TP02 / PC12

- fecha a interpretação estática das respostas de quatro bytes usadas pelo monitor Ladder do PC12;
- confirma cinco produtores `PG0A` com `Q=04`;
- identifica dois consumidores nativos de 32 bits, tipos internos `4` e `7`;
- tipo `4`: `b0 | b1<<8 | b2<<16 | b3<<24`;
- tipo `7`: `b1 | b0<<8 | b3<<16 | b2<<24`;
- confirma exibição decimal `%010u` e hexadecimal `%08X`;
- confirma avanço de quatro bytes do cursor da resposta;
- documenta o seletor interno `[objeto+0x12DE]` entre os dois formatos;
- adiciona auditor reproduzível `scripts/analyze_pc12_monitor_q4_response.py` e vetor estático de referência.

Nenhuma nova transmissão PG é habilitada nesta versão. A validação física das respostas `Q=4` em TP02 real permanece pendente.

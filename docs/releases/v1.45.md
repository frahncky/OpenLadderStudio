# OpenLadderStudio v1.45

## TP02 — respostas do monitor Ladder

- fecha a tabela nativa do parser de respostas do monitor para os tipos `0..7`;
- registra consumo por tipo: `0,1,1,0,4,2,2,4` bytes;
- implementa decoder offline `Tp02PgProtocol.DecodeMonitor(...)`;
- confirma tipo 1 ativo-alto e tipo 2 ativo-baixo;
- confirma tipos 5/6 como igualdade/desigualdade no segundo byte;
- fecha os dois formatos Q=4:
  - tipo 4: little-endian;
  - tipo 7: big-endian por palavra de 16 bits, com a primeira palavra como parte baixa do valor de 32 bits;
- adiciona auditoria reproduzível do `pc12.exe` original e autotestes dos oito tipos;
- atualiza a evidência do comando PG0A no catálogo.

## Segurança

Nenhum novo comando foi liberado para transmissão. Toda a nova lógica é de decodificação offline.

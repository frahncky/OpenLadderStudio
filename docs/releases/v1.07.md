# OpenLadder Studio v1.07

## Estabilização automática do TP-232PG

Esta versão corrige o comportamento observado em bancada no qual a primeira tentativa de conexão PG podia falhar e a segunda funcionar imediatamente.

### Correções

- adicionada espera inicial para estabilização do TP-232PG antes do primeiro `CON-ICB<CR>`;
- o perfil fisicamente mais estável, `19200 8O1 / DTR on / RTS off`, passou a ser testado primeiro e com mais tentativas;
- a validação PG agora executa duas varreduras internas automaticamente;
- entre as varreduras, a porta é fechada e as linhas DTR/RTS são rearmadas sem envio de bytes;
- a segunda varredura usa tempos de estabilização e recepção maiores;
- o fallback para Computer Link só é tentado depois das duas varreduras PG falharem;
- o log identifica `PG AUTO-RETRY` e `PG RECOVERY`, facilitando o diagnóstico.

### Segurança

O processo de recuperação não envia RUN, STOP, comandos de limpeza, escrita ou qualquer comando PG desconhecido. Durante a detecção PG, o único quadro transmitido continua sendo `CON-ICB<CR>`.

O objetivo é reproduzir automaticamente, dentro de um único clique, o comportamento que antes exigia executar a validação duas vezes manualmente.

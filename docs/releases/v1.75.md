# OpenLadder Studio v1.75

Esta versão deixa o diagrama Ladder mais legível e mais fácil de começar a montar.

## Novidades

- **Elementos com desenho novo.** Contatos e bobinas têm traço mais firme e um fundo arredondado discreto, que fica verde quando o elemento está energizado na simulação.
- **Endereço em etiqueta.** O endereço de cada contato e bobina (X0001, Y0001...) aparece numa etiqueta arredondada acima do símbolo, mais fácil de achar numa linha cheia.
- **Blocos com cor por tipo.** Temporizador, contador, função e END têm cantos arredondados e uma cor própria no cabeçalho, para distinguir um do outro de relance.
- **Guia no espaço livre.** Abaixo de "Nova linha", enquanto o programa é curto, o editor mostra em três passos como montar uma linha. O guia some sozinho quando o programa ocupa o espaço.

As cores continuam vindo do tema escolhido, escuro ou claro.

## Antes de atualizar

- O formato dos arquivos não mudou nesta versão.
- O comentário de linha da v1.73 continua com compatibilidade de mão única: um projeto com comentário de linha não abre em instalações anteriores à v1.73.
- A leitura do PLC real ("Acender diagrama") continua sem validação no equipamento físico.

## Limitações conhecidas

- Na largura mínima da janela (1280 x 800), a barra de rolagem horizontal do editor aparece mesmo quando o diagrama deveria caber.
- O painel PROPRIEDADES encurta a lista INSTRUÇÕES; na janela mínima, Bobina, SET e RESET exigem rolagem.

O instalador e seu SHA-256 ficam disponíveis para download pelo atualizador do programa.

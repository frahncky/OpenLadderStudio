## OpenLadder Studio v0.69

### Atualização
- corrigida a corrupção de tokens técnicos causada pela normalização PT-BR;
- `browser_download_url` volta a permanecer intacto no parser da API do GitHub;
- `/releases/download/` deixa de ser traduzido dentro das URLs de atualização;
- o caminho técnico `PC12_v2.1_Windows7_v3_portatil` deixa de receber acentuação dentro de URLs;
- auditoria passa a restaurar e validar esses tokens antes da compilação, bloqueando novas releases com URLs corrompidas.

### Compatibilidade
- preservada a atualização automática pelo próprio OpenLadder Studio nas versões futuras;
- mantida a interface clara introduzida na v0.68;
- mantido o instalador compatível com Windows 7 e o pré-requisito .NET Framework 4 quando necessário.

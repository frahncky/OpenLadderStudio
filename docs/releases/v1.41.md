# OpenLadder Studio v1.41

## Clear System, Clear Data e Clear Program identificados

O cruzamento do menu nativo do PC12 com a tabela de handlers OWL fechou três
comandos antes tratados como desconhecidos:

- `04 00 FB` = Clear System;
- `11 00 EE` = Clear Data;
- `03 00 FC` = Clear Program e preparação da gravação PG33.

O comando `35` foi localizado no fluxo assíncrono de monitoramento e passou a ser
descrito como troca de dados do monitor, ainda com payload de semântica parcial.

O catálogo em `Ferramentas > Comandos PG do PC12` foi atualizado. Os quatro
comandos permanecem bloqueados para TX.

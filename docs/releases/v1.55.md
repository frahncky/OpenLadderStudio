# OpenLadder Studio v1.55

## TP02 — CHECK LOGIC antes do RUN remoto

A v1.55 nasce de uma validação física no WEG TP02-60MR em 14/09/2026.

O quadro PG de RUN `02 00 FD` foi transmitido uma única vez. A confirmação imediata por HELLO falhou por instabilidade do enlace, mas uma reconexão posterior identificou o controlador em **RUN**, validando fisicamente o comando. Durante a execução, porém, o LED **ERR** permaneceu aceso. Ao colocar o PLC em STOP pelo PC12 original, o LED ERR apagou.

O readback do projeto de fronteira de 323 palavras mostrou repetição de sequências equivalentes a:

```text
STR X0001
OUT C0001
```

A ajuda oficial do PC12 lista **Double OUT** entre os erros de autodiagnóstico. O projeto de fronteira era adequado para validar PG33/PG34, mas não era um programa de execução válido para RUN por repetir a mesma bobina `OUT` muitas vezes.

## Correção

Antes de qualquer preflight serial do RUN, a v1.55 executa um **CHECK LOGIC local** sobre o projeto Ladder aberto. Se houver erro conhecido, o RUN é bloqueado e **nenhum quadro `02 00 FD` é transmitido**.

As verificações implementadas nesta primeira etapa são:

- **Double OUT** — a mesma bobina `Y`/`C` usada por mais de um `OUT`;
- **T/C Double Used** — o mesmo registrador `V` usado simultaneamente como TMR e CNT;
- **FUN. Double Used** — repetição das funções de instância única documentadas pelo fabricante: F-52, F-53, F-55, F-58 e F-59;
- pares obrigatórios F-01/F-02 (MCS/MCR), F-03/F-04 (JCS/JCR), F-07/F-08 (SKIP/ENDS) e F-46/F-47 (FOR/NEXT).

A validação usa a pré-compilação TP02 já existente e não abre a porta serial.

## Segurança

A v1.55 não altera o quadro RUN nem adiciona novos comandos de estado.

O fluxo permanece:

```text
CHECK LOGIC local
-> conexão já estabelecida
-> preflight STOP/RUN por HELLO+F0
-> confirmação explícita do operador
-> TX RUN 02 00 FD no máximo UMA vez
-> verificação posterior por HELLO
```

Não existe retransmissão automática do RUN. STOP remoto continua protegido até validação física independente.

## Estado físico consolidado

Confirmado em bancada:

```text
PG33 multibloco: 17 blocos / 323 palavras / ACK 00 00 FF
PG34 multipágina: páginas 0,80,160,240,320 / END=0322
Comparação: projeto no TP02 idêntico ao projeto atual
RUN remoto: 02 00 FD efetivamente colocou o TP02 em RUN
HELLO RUN após reconexão: estado RUN detectado
```

O LED ERR observado durante o RUN do projeto de fronteira é tratado como problema de lógica do projeto de teste, não como falha do transporte PG33/PG34 nem do quadro RUN.

# OpenLadder Studio v0.94

## Pesquisa Continua IA - TP02

A v0.94 transforma o Agente IA Adaptativo da v0.93 em uma sessao de pesquisa persistente para reduzir drasticamente a necessidade de recompilar o laboratorio a cada nova captura.

### Principais mudancas

- motor PG Lab 1.9;
- modo visual renomeado para `PESQUISA CONTINUA IA`;
- nova classe `Tp02PersistentOpenAiAgent`;
- conversa da Responses API encadeada por `previous_response_id`;
- Structured Outputs com JSON Schema para a proxima acao;
- a porta COM permanece aberta enquanto o enlace continuar util;
- limite local de 200 decisoes ou 60 minutos por campanha;
- o usuario pode interromper a campanha a qualquer momento;
- cada turno registra o `response_id`, estado serial, TX/RX e historico recente;
- probes tentados e probes com RX sao acompanhados durante toda a sessao;
- `finish` fica bloqueado ate o criterio local `PROTOCOL_CLOSURE_READY` ser atendido.

### Criterio de fechamento READ-ONLY

Para concluir automaticamente a fase atual, o OpenLadder exige enlace estabelecido, F0 validado, execucao de todos os probes READ-ONLY atuais, RX real no F0, RX real na leitura de programa e RX em pelo menos uma leitura de sistema.

Esse fechamento vale somente para a investigacao de leitura. Ele nao libera download ou escrita.

### Seguranca

Nao existe acao para bytes arbitrarios. A IA continua limitada a `open_profile`, `set_lines`, `hello`, `probe`, `passive`, `wait` e `finish`. Permanecem bloqueados escrita, WBP/download, RUN/STOP remoto, apagamento, firmware e qualquer quadro fora da allowlist local.

A chave da OpenAI API continua protegida pelo DPAPI do Windows e nao e salva nos relatorios.

# OpenLadder Studio v1.74

Esta versão corrige uma falha da v1.73 ao abrir o programa com a escala de tela do Windows em 125% ou 175%. Se você usa uma dessas escalas, atualize.

## Correção

- Corrigido: com a escala de tela do Windows em 125% ou 175%, a v1.73 mostrava "O OpenLadder Studio encontrou um erro inesperado. Erro ao criar identificador de janela." toda vez que o programa era aberto.
- A causa estava na árvore do painel PROJETO, que calcula a altura das linhas a partir da escala da tela. Quando o resultado dava ímpar, a árvore recriava a própria janela no meio da abertura do programa. Agora essa altura sai sempre par, e o programa abre normalmente em qualquer escala.
- Com a escala em 100% ou 150% a v1.73 não tinha o problema, e nada muda para quem usa essas escalas.

## Antes de atualizar

- **O comentário de linha da v1.73 continua com compatibilidade de mão única.** Um projeto com pelo menos um comentário de linha é gravado em um formato novo (`PC12-LADDER|3`), e uma instalação anterior à v1.73 recusa o arquivo inteiro. Se você compartilha arquivos entre computadores, atualize todas as instalações antes de comentar linhas.
- A leitura do PLC real ("Acender diagrama") continua sem validação no equipamento físico.

## Limitações conhecidas

- Na largura mínima da janela (1280 x 800), a barra de rolagem horizontal do editor aparece mesmo quando o diagrama deveria caber.
- O painel PROPRIEDADES encurta a lista INSTRUÇÕES; na janela mínima, Bobina, SET e RESET exigem rolagem.

O instalador e seu SHA-256 ficam disponíveis para download pelo atualizador do programa.

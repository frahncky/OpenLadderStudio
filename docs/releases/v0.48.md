# OpenLadder Studio v0.48

## Atualização automática

- o OpenLadder Studio verifica em segundo plano se há uma release mais recente ao iniciar;
- quando há uma atualização disponível, a barra inferior mostra um aviso clicável que abre a tela de atualização;
- falhas de rede não interrompem o uso do aplicativo.

O instalador e seu arquivo SHA-256 são publicados pelo workflow de release.

# OpenLadder Studio v1.65

## Ferramentas de edição no início do painel

- O ponteiro **Selecionar / mover** aparece no topo da paleta, logo após a busca.
- Seleção, adição e exclusão de linha e remoção de elemento ficam agrupadas antes dos componentes Ladder.
- A biblioteca de contatos, saídas, temporização e funções aparece depois das ações de edição.
- O ponteiro inicia ativo ao abrir o editor e continua acessível pela tecla Esc.

Esta versão reorganiza a interface para reduzir a rolagem e deixar a ferramenta de edição sempre fácil de encontrar.

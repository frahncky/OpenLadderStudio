# OpenLadder Studio v1.38

## Protocolo PG consolidado a partir do PC12 original

Os quadros curtos recuperados do `pc12.exe` v2.1 passam a ter uma fonte canônica
no núcleo. A implementação gera o checksum que fecha a soma módulo 256 em `FF`
e possui autoteste offline para todos os quadros catalogados.

Quadros: `01 00 FE`, `02 00 FD`, `03 00 FC`, `04 00 FB`, `0F 00 F0`,
`11 00 EE` e `F0 00 0F`.

O fluxo RUN usa agora o quadro canônico `02 00 FD`. As travas permanecem:
`01` (Program/STOP sem validação física independente), `03`, `04`, `11` e `0F`
continuam bloqueados. `0F 00 F0` permanece classificado como Clear All Memory.

O novo autoteste verifica os bytes, checksums, denylist e cópia defensiva usada
pelo transmissor. O teste não abre porta serial.

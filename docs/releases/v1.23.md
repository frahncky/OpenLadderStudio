# OpenLadder Studio v1.23

## Gravação do projeto atual por PG33

A tela de validação PG33 passa a receber o projeto aberto no editor Ladder e oferece o comando **GRAVAR PROJETO ATUAL**.

O primeiro fluxo produtivo permanece deliberadamente limitado ao envelope já validado em bancada:

- um único quadro PG33;
- até 20 instruções lógicas;
- até 80 palavras de máquina;
- contatos Boolean X/Y/C;
- saídas Y/C;
- TMR/CNT com preset literal;
- SET/RST de Y;
- F-13w ADD com operandos D, D e literal;
- F-00 END obrigatório como última palavra.

Qualquer instrução fora desse subconjunto bloqueia a operação antes de abrir a porta serial.

## Fluxo protegido

1. compila o projeto atual e apresenta contagem de instruções/palavras;
2. exige confirmação explícita e PLC em STOP;
3. qualifica HELLO STOP e F0 na mesma porta/perfil;
4. lê e salva o programa atual como backup;
5. bloqueia se o backup tiver mais de 80 palavras;
6. transmite o projeto em um único PG33;
7. exige ACK físico `00 00 FF`;
8. reacquire a sessão e compara o readback com o projeto compilado;
9. se houver divergência confirmada, restaura o backup uma única vez;
10. se a comunicação de verificação falhar, não faz retransmissão nem restauração cega.

Nenhum comando RUN remoto, Clear All, WBP ou escrita `0x09` foi adicionado.

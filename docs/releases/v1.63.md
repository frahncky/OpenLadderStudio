# OpenLadder Studio v1.63

## Interface multi-PLC e edição Ladder

- A paleta visual agora é compartilhada pelo shell, editor e painéis de instruções.
- As ações **Adicionar linha**, **Excluir linha selecionada** e **Apagar elemento selecionado** aparecem no início do painel de edição.
- O menu **Ações** reúne programação, comunicação com o controlador e engenharia reversa.
- Os painéis do projeto, do editor e das instruções podem ser redimensionados.
- A interface usa nomes genéricos para os recursos multi-PLC.

Esta versão altera a interface do Studio. Não altera os quadros nem os parâmetros dos protocolos de comunicação.

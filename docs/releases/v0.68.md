## OpenLadder Studio v0.68

### Interface
- nova interface clara do OpenLadder Studio aplicada como camada visual final do build;
- barra superior reorganizada, com comandos principais mais legíveis e ícones coloridos;
- destaque para Compilar, Transferir, Monitor e Simulador;
- editor Ladder permanece como área central principal, preservando a funcionalidade da v0.67.

### Atualização
- corrigida a detecção dos arquivos de atualização para não depender da ordem dos campos no JSON da API do GitHub;
- os endereços do instalador e do SHA-256 passam a ser construídos diretamente a partir da versão publicada;
- mantido fallback de compatibilidade para Windows 7;
- futuras correções passam a ser publicadas em uma nova versão, evitando substituição de assets de uma release que já esteja sendo consultada pelo atualizador.

### Instalação e Windows 7
- instalador passa a aceitar Windows 7 6.1;
- Microsoft .NET Framework 4 é incorporado ao setup e instalado somente quando necessário;
- preservada a atualização por dentro do próprio OpenLadder Studio.

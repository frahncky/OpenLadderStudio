# OpenLadder Studio v1.51 — sessão PG robusta e prova de paginação longa

## Evidência física de 2026-09-14

A campanha v1.50 confirmou o HELLO somente após recuperação da COM, mas transmitia F0 cedo demais. O leitor PG robusto, com warm-up, nova sessão limpa e temporização conservadora, completou posteriormente no TP02 real:

```text
HELLO -> F0 -> 38 -> PG34@0000 -> parser Ladder
```

Capturas confirmadas:

```text
HELLO RX: 80 01 09 75
F0 TX:    F0 00 0F
F0 RX:    00 02 10 22 CB
38 TX:    38 00 C7
38 RX:    00 02 00 04 F9
34@0000:  34 03 00 00 A0 28
```

A página PG34 retornou `LEN=F0`, checksum total `FF` e reconstruiu corretamente um programa de 3 words:

```text
0000  STR NOT X0001
0001  OUT Y0001
0002  F-00 END
```

Resultado: 0 BRAW divergentes e 0 UNKNOWN.

## Sessão robusta

A sequência física que funcionou mantém:

- warm-up prévio do TP-232PG;
- fechamento/reabertura da COM para uma sessão limpa;
- estabilização da porta;
- até 6 HELLO por sessão;
- ~450 ms entre HELLO confirmado e F0;
- até 4 tentativas de F0, com 350 ms entre tentativas;
- ~420 ms entre F0 e 38;
- ~450 ms antes da primeira leitura PG34;
- retry por sessão quando HELLO/F0 não confirmam.

38/PG34/PG0A não devem ser classificados como falha quando o estágio F0 não foi estabelecido.

## Prova física PG34 longa

A v1.51 adiciona ferramentas auxiliares para fechar o principal asterisco restante da paginação PG34:

- `GenerateTp02Pg34BoundaryProject.ps1`: gera offline um projeto de 323 machine words, sem saída física Y;
- `AnalyzeTp02Pg34BoundarySession.ps1`: audita offline os arquivos de uma sessão PG e classifica cada fronteira.

O projeto-teste possui 161 rungs `STR X0001 -> OUT C0001` mais `F-00 END`, totalizando 323 words e END no passo 322. Isso força o leitor a pedir:

```text
0x0000 -> 34 03 00 00 A0 28
0x0050 -> 34 03 00 50 A0 D8
0x00A0 -> 34 03 00 A0 A0 88
0x00F0 -> 34 03 00 F0 A0 38
0x0140 -> 34 03 01 40 A0 E7
```

Critérios de fechamento físico:

1. `0000 -> 0050` = segunda página fisicamente comprovada;
2. `00F0 -> 0140` = troca `START_H 00 -> 01` fisicamente comprovada;
3. 5 páginas, 323 words, END 0322, BRAW=0 e UNKNOWN=0 = campanha de referência completa.

## Segurança

Nenhum comando novo foi liberado automaticamente. As ferramentas adicionadas nesta versão são offline. A leitura PG permanece restrita a HELLO/F0/38/34.

Para executar o ensaio de 323 words é necessário gravar temporariamente um programa de teste no PLC. Essa gravação deve ser feita somente após backup do programa existente, com PLC em condição segura/STOP e restauração ao final. O projeto-teste não referencia saídas físicas `Y`, mas não deve ser colocado em RUN em uma máquina/processo real sem isolamento adequado.

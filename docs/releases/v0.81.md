## OpenLadder Studio v0.81

### Formato de projeto
- Corrigido um defeito que fazia o projeto **salvar e depois nao abrir**. O til (`~`) separa a via serie da via paralela dentro de cada celula do arquivo `.pladder`, mas nao estava sendo escapado: um til no conteudo gravava um separador a mais, e o arquivo era recusado na leitura seguinte com "quantidade de ramificacoes invalida".
- O til passa a ser gravado como `%7E`. Arquivos ja gravados continuam legiveis, porque a leitura sempre soube decodificar essa sequencia.
- O autoteste do formato passa a cobrir os tres separadores (`|`, `~` e `:`) dentro do conteudo, para o caso nao voltar.

O instalador e seu SHA-256 ficam disponiveis para download pelo atualizador do programa.

# OpenLadder Studio v0.93

## Agente IA Adaptativo TP02

A v0.93 muda a estrategia do Laboratorio PG: em vez de criar uma nova versao do programa para cada nova captura, o laboratorio pode manter uma sessao de bancada e consultar a OpenAI API depois de cada observacao.

### Fluxo

1. o operador seleciona a COM;
2. ativa `AGENTE IA ADAPTATIVO` e configura uma `OPENAI_API_KEY` uma unica vez;
3. o programa envia para o modelo apenas o estado da sessao: perfil serial, DTR/RTS, TX/RX recente, HELLO/F0 validados e historico curto;
4. o modelo responde com uma unica proxima acao estruturada;
5. o Safety Gate local valida a ordem;
6. somente depois da validacao o programa executa a acao no TP02;
7. o novo RX volta para o modelo e o ciclo continua ate `finish`, parada do usuario ou limite local de 40 decisoes.

### Acoes permitidas ao agente

- `open_profile`: abrir somente um dos perfis seriais definidos no pacote;
- `set_lines`: alterar DTR/RTS, sem transmitir bytes, e observar RX espontaneo;
- `hello`: enviar somente o `CON-ICB<CR>` protegido;
- `probe`: executar somente um `probe_id` READ-ONLY habilitado e allowlisted;
- `passive` / `wait`: apenas escutar a porta;
- `finish`: encerrar a campanha.

Nao existe acao `send_hex`. A IA nao consegue fornecer bytes arbitrarios ao executor.

### Bloqueios locais permanentes

O agente nao pode solicitar nem executar escrita, WBP/download, RUN/STOP remoto, apagamento, firmware ou quadros fora da allowlist. O `38 00 C7` continua dependendo de F0 conhecido na mesma sessao, pois passa pelo mesmo `IsStepAllowed` do modo local.

### Evidencia que motivou a mudanca

Na captura da v0.92, `F0 00 0F` ficou silencioso nas variantes iniciais, mas a transicao `RTS TX=on -> RX=off` provocou novamente `HELLO-STOP 80 01 09 75`. Isso mostrou que a investigacao precisa adaptar a proxima acao em funcao de cada resposta, sem recompilar o software a cada hipotese.

### OpenAI API

O agente usa a Responses API e, por padrao, o modelo `gpt-5.6` (pode ser substituido pela variavel de ambiente `OPENAI_MODEL`). A chave e armazenada criptografada pelo DPAPI do Windows em `%LOCALAPPDATA%\OpenLadderStudio\Secrets` e nunca e escrita nos relatorios ou no repositorio.

A utilizacao da OpenAI API possui faturamento separado da assinatura do ChatGPT.

INTERPRETATION GUARDRAILS
------------------------------------------------------------------------------------------------
* Escrita em F_TIMEOUT/F_ERROR/F_CHECKSUM mostra apenas estado interno da rotina.
* Uma comparação com RX_BUF pode ajudar a reconstruir o ACK, mas não constitui validação física.
* Nenhum payload de resposta deve ser inventado sem fluxo de dados explícito ou captura.
* Este script nunca chama a rotina 0x0046F5E6; apenas examina os bytes do executável.

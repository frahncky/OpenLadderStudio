STATIC INTERPRETATION
----------------------------------------------------------------------------------------------------
* CALL direto Write PLC Program -> rotina TX é correlação estática forte do caminho de envio.
* Os vários CALLs consecutivos são cercados por testes de flags de comunicação; não devem ser contados como 15 quadros distintos sem execução do fluxo.
* O construtor 0x33 e o cálculo de checksum estão no mesmo caminho que antecede os CALLs de TX.
* O conteúdo mostrado antes de cada CALL continua sendo estático: branches podem selecionar caminhos diferentes.
* Nenhuma ocorrência 09/0F deve ser tratada como download completo sem reconstruir a ordem efetiva dos quadros.
* 0F 00 F0 (Clear All Memory) continua bloqueado e este script nunca executa TX.

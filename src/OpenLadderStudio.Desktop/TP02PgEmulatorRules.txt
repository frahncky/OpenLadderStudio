# TP02 PG Emulator - regras externas de resposta
# Formato:
#   CMD_HEX|DELAY_MS|RESPONSE_HEX|LABEL
# Exemplo:
#   A1|150|00 00 FF|ACK temporario para candidato A1
#
# Regras so devem ser adicionadas depois que o opcode aparecer em captura do PC12.
# O build injeta estas regras no switch do emulador sem alterar TP02PgEmulator.cs.
#
# Para descobrir RUN/STOP sem tocar no PLC fisico, execute:
#   DiscoverTp02PgRunStop.bat
# A rotina usa PC12 original + par COM virtual + emulador com --no-auto-ack,
# captura STOP e RUN separadamente e gera TP02-PG-RUNSTOP-DISCOVERY-*.txt.
# Nao copie automaticamente os candidatos para este arquivo: primeiro confirme
# o quadro e a resposta/semantica esperada.
#
# Comandos ja tratados nativamente e portanto proibidos aqui:
#   F0 38 34 33 0A 14
#
# 33 = Write PLC Program / Program Data confirmado por analise estatica do
# pc12.exe e emulacao Unicorn offline do construtor original.

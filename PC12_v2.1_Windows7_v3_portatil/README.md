# Compatibilidade de URLs públicas

Este diretório preserva os endereços de `version.txt` e `TP02-PG-Tests.json` usados por versões já instaladas do OpenLadder Studio.

Os fontes e arquivos canônicos estão em [`src/OpenLadderStudio.Desktop`](../src/OpenLadderStudio.Desktop/). Não edite estas cópias diretamente: execute `scripts/SyncCompatibilityMetadata.ps1` após atualizar os arquivos canônicos. O CI verifica que as cópias são idênticas.

Consulte a [estrutura do repositório](../docs/repository-layout.md).
